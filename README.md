## 📄 페이지별 상세 구성

### 1. About Us (`about.html`)
- **소개 글**: 사람과 기술을 연결하는 팀의 목표
- **우리들의 이야기**: 문제 해결 및 가치 전달 지향점
- **핵심 가치**: 사용자 중심 / 협업과 소통 / 문제 해결 / 지속적 성장
- **팀 소개 및 미션**: 디지털 경험 개선 목표 및 연락처

### 2. Contact Us (`contact.html`)
- **문의 양식(Form)**:
  - 이름, 이메일, 연락처, 문의 내용 입력 폼
  - 보내기 / 초기화 버튼
- **회사 정보**: 주소, 전화번호, 대표 이메일 안내

## 🛠 Git 협업 규칙 및 워크플로우

1. **브랜치 전략**
   - 각 기능/역할별 개별 브랜치(`AAA`, `BB`) 생성 후 독립 작업
2. **Pull Request & 코드 리뷰**
   - 작업 완료 후 `main` 브랜치를 향해 PR 생성
   - 변경 사항 확인 및 상호 검토 후 머지
3. **최신화(Sync)**
   - `main` 병합 완료 후 각 로컬 브랜치에서 `main`을 pull/merge하여 최신 상태 유지
